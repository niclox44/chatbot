# Setter — frontend

Prototipo frontend de una plataforma para configurar y supervisar un setter de IA en Instagram.

## Ejecutar en local

```bash
npm install
npm run dev
```

Para comprobar la compilación de producción:

```bash
npm run build
```

## Alcance actual

- Landing pública responsive.
- Panel principal con datos de demostración.
- Bandeja de conversaciones y respuesta editable.
- Contactos y estados comerciales.
- Configuración visual del asistente y del negocio.
- Simulador de conversación.
- Pantalla de integraciones.
- Entradas escalonadas al hacer scroll y cabecera flotante con progreso.
- Tarjetas con profundidad, brillo y estado activo según el cursor.
- Carrusel continuo de integraciones y escenas interactivas del proceso.
- Transiciones entre pantallas del panel y soporte para movimiento reducido.

Todos los datos viven únicamente en el estado del navegador. Todavía no hay autenticación, base de datos, conexión con Instagram, n8n ni servicios de IA.
